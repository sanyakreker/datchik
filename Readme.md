Название проекта:Система мониторинга температуры серверных помощений с помощью термодатчика ODTEMP-1.

Проект представляет собой систему файлов с кодом для обеспечения мониторинга компьютерных систем.

Возможности проекта:
1.Сбор данных температуры с датчика ODTEMP-1 (системное название:DS18B20) по HID протокол.
2.Запись всех измерений в базу данных SQLite.
3.Веб-интерфейс с графиком зависимости температуры от реального времени.
4.Отправка уведомлений на почтовой адрес при превышении порога температуры.
5.Логирование (запись) событий в файл и консоль.

Для мониторинга требуется: наличие термодатчика ODTEMP-1, терминал git на ос Windows или терминал оc linux (с раширеннными правами),
наличие DB Browser for SQLite для работы с данными,почтовой адрес для рассылки уводемлений о перегреве

Структура проекта:

1)data_env - файл с данными для рассылки на почтовой адрес.
2)database.py - файл для создания базы данных по температуре 
3)logger.py - для записи логов
4)monitor.db - sqllite массив данных по температуре
5)monitor.log - файл с всеми логами
6)moniotr - головной файл, в котором соединятся другие файлы для реализации проекта
7)state.py -  файл хранящий константы
8)vizual.html - файл хранящий  html код для визуала локальной страницы
9)web_server.py - файл для создания веб сервера по мониторингу температуры
10)zapros_sql.sql - файл с sql запросами для работы с файлом monitor.db
